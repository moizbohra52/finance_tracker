# Product Requirements

## Authentication
- Splash
- Onboarding
- Register
- Login
- Forgot password
- Reset password
- Change password
- Logout
- Delete account

## Profile
- Name
- Email
- Mobile
- Avatar
- Currency
- Timezone
- Edit profile

## Finance
- Opening balance
- Multiple accounts
- Income
- Expense
- Transfer
- Categories
- Unified transaction history
- Search/filter
- Monthly summaries

## Khata
- Contacts/persons
- Opening ledger balance
- Credit/debit
- Receive/pay
- Outstanding receivable/payable
- Transaction timeline
- Due dates/reminders

## Reports
- Income
- Expense
- Net cash flow
- Category analysis
- Account analysis
- Receivable/payable
- Monthly/yearly charts

## Budget
- Monthly/custom budgets
- Category budgets
- 75/90/100% alerts

## Recurring
- Daily/weekly/monthly/yearly/custom
- Rent, salary, EMI, subscription, insurance etc.

## Reminder
- One-time and repeating reminders
- Related contact/account/transaction
- Notification time

## Settings
- Theme
- Accent color
- Currency
- Language
- Date/number format
- Notification controls
- Backup/export
- Privacy/terms/about

## Acceptance philosophy
Every feature must support:
- validation
- loading
- success
- empty
- error
- offline behavior where relevant
- confirmation for destructive actions
