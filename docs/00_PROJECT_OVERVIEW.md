# Project Overview

## Product
A modern Personal Finance + Digital Khata app.

## Primary users
Individuals who need one place to track:
- opening balance
- income
- expenses
- cash/bank/UPI balances
- money to receive
- money to pay
- personal lending/borrowing
- budgets
- recurring payments
- reminders

## Product principles
1. Balance must always be understandable.
2. Adding a transaction should take seconds.
3. The app should remain useful offline.
4. Financial calculations must be deterministic.
5. Privacy and account isolation are mandatory.
6. UI should be modern but not complicated.

## Main navigation
- Home
- Transactions
- Khata
- Reports
- Profile/Settings

## Global add action
A central + action provides:
- Income
- Expense
- Credit
- Debit
- Transfer
- Reminder

## Future-ready
Architecture should permit:
- shared/family accounts
- business mode
- invoices
- loans
- investments
- bank integrations
- AI financial assistant
without prematurely implementing them.
